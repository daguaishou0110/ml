# 机器学习辅导

机器学习 / 数据挖掘课程材料：大纲、各课具体教学内容、教学网页。

## 内容

- `课程大纲.md` / `课程大纲-简版.md`：课程结构
- `各课具体教学内容.md` / `.docx`：可授课讲义正文
- `教学网页/`：本地打开 `index.html` 即可浏览（含公式渲染与互动演示）

## 教学网页

用浏览器打开：

```text
教学网页/index.html
```

建议联网加载 KaTeX；修改讲义后如需同步网页，需重新生成 `content.js`。
